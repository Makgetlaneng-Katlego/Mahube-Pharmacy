# Mahube Pharmacy

A simple Android application for Mahube Pharmacy.

## About


A lightweight Android app that lets customers browse pharmacy
     products, view opening hours, and get in touch with the pharmacy. 

This is a bare-bones native Android project built with Gradle.

## Tech Stack

- **Language:** Kotlin 
- **Platform:** Android (native)
- **Min SDK:** 

## Requirements

- Android Studio (latest stable)
- JDK 17
- Android SDK matching the project's `compileSdk`
